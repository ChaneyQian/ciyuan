# 词源

**字溯其源 · 声律成境** —— 在宣纸上写一个字，看它从楷书一路退回甲骨文，再活成它所画的那件东西。

写「山」，三座并立的峰先在字里显形，然后真的隆起成山；写「月」，半轮甲骨月散作一团墨，月亮从墨里浮出来；
写「龙」，一条墨龙追着你笔尖上的火珠游。写下「云」之后，字钮里的「雨」会亮起——因为《声律启蒙》开篇就是「云对雨」。

纯静态网页：一个 `index.html` 加几份脚本，没有构建步骤，没有依赖。

## 运行

```bash
python -m http.server 4180
```

然后打开 <http://localhost:4180>。直接双击 `index.html` 也能用。

要发布成网站：把仓库推到 GitHub，在 Settings → Pages 里选 `main` 分支根目录即可。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 键盘直接打字（中文输入法） | 字落在笔尖（鼠标所在处），化形 |
| 点下方的字钮 | 同上，落在画面里合适的位置（手机上用这个） |
| 拖动 | 落墨 |
| 按住 `Shift` 拖动 | 泼水，把墨冲开 |
| `1` `2` `3` | 换墨色：墨 / 朱 / 青 |
| **自在** | 随机取《声律启蒙》一阕，让它自己一句句写成一幅画 |
| **溯源** | 默认关：字直接化形。开：先演示字形演变（每个字第一次完整，之后从简） |
| **手写** | 开了以后拖动不再落墨，而是写字：在纸上写一个字，停笔即判，认出来就化形 |
| **拼音** | 开了以后不靠系统输入法：直接敲 `shan`、`yue`、`long`，空格 / 数字选字 |
| **有声** | 乐声开关（第一次动笔时自动打开） |
| **留影** | 存一张 PNG，带印章与题句 |

## 彩蛋

纸上还藏了几段小戏：不提示、不高亮，凑齐某几个字（或者把同一个字接连写上几遍）才会演，十来秒，演完画面照旧。举两个：

- **酒、剑、灯** 同在画里（先后不论）——「醉里挑灯看剑，梦回吹角连营」（辛弃疾《破阵子》）：灯下看剑，入梦，连营吹角，铁骑冲过。
- 接连写九次 **曙** —— 九日临空，纸被烤暖，禾稼焦卷；羿一箭一箭射落，只留一个。

其余的自己去碰。「自在」和手卷里不演；戏演着照样可以写字，写「空」则一并散去。
做法在 `js/eggs.js`：一张表（凑哪些字、题哪一句、一段按时间推进的戏）加一个很小的运行器。

## 三件事

### 一、字形溯源（开关，默认关）

打开「溯源」后，每个字先以今天的楷书落纸，然后倒着走完它的历史：

**楷书 → 隶书 → 小篆 → 金文 → 甲骨文 → 化形**

越往回越像画，走到最古的象形时题一句字源（「象群峰并立之形」），墨散开，字变成实物。

- 甲骨文、金文、小篆是真实的历史字形，轮廓数据在 `js/glyph-data.js`（145 个字、324 个字形）。能活的 87 个字里有 66 个带古文字，其中 37 个能一直退到甲骨文。
- 楷书、隶书用系统字体（Windows 的楷体 / 隶书，macOS 的 Kaiti SC / Libian SC）。机器上没有隶书就跳过这一体，不拿别的字体冒充。
- 某一体没有可靠字形的字只演示有的那几体。「雷 松 莺 鹤 蝶 楼 灯 昼 霜 曙 蕖 鸿 珠 泪 枫 叶 蜂 猿 笔 茶 笛」这 21 个字在来源里没有古文字字形，目前只有楷、隶两体。
- 渐变的做法：每一体画到离屏画布，在墨迹里撒 1500 个点，相邻两体的点就近配对，墨点在两组位置间游走。

### 二、中式乐器

全部用 WebAudio 现场合成，不带任何音频文件。

| 乐器 | 做法 | 谁在用 |
| --- | --- | --- |
| 古琴 | Karplus–Strong 拨弦，暗而长，带吟猱与走手音；另有泛音 | 山、松、菊、月；底乐 |
| 古筝 | 明亮的拨弦，刮奏 | 水、虹、柳、荷、舟 |
| 琵琶 | 短促颗粒，轮指、扫弦 | 雨、花、草、剑 |
| 笛 / 箫 | 正弦泛音 + 气声 + 倚音 + 颤音 | 竹、梅、莺 / 云、烟、霞、风、雁、夜 |
| 编钟 / 磬 | 非谐泛音叠加 | 钟、楼、日 / 雪、星、灯 |
| 鼓 / 木鱼 | 降调正弦 + 噪声 | 鼓、雷、龙 / 溯源时每退一体一声 |

- 音高只用五声音阶（宫商角徵羽）。写「春夏秋冬」会换调：春-角、夏-徵、秋-商、冬-羽。
- **平仄入乐**：每个字落纸时古琴应一声——平声字是平直的长音，仄声字是带滑音的折音。
- 凑成一副对仗时，上下句各一声，再合为五度。

### 三、词库：从《声律启蒙》起，随古文扩充

`js/shenglv-data.js` 是清人车万育《声律启蒙》全文（上下卷三十韵，九十阕）。对仗与题句都从这份文本里算出来：

- **能活的字**起先是 44 个，都是书里反复出现的物象：日月星云雨雪风雷虹霞烟 · 山水 · 竹松柳梅花荷菊草 · 鸟燕雁莺鹤 · 蝶虫鱼龙 · 舟楼钟鼓剑火灯 · 春夏秋冬夜昼空。
- 字库不再限于韵书里的字，演一篇古文就添一批：
  - 《洛神赋》22 个：霜雾光曙 · 川波渊岩 · 林兰芝蕖 · 鸿凫羽 · 珠泪，以及 **旗 车 神 人 马**；
  - 《琵琶行》4 个：枫、泉、冰、酒。
- 又回到《声律启蒙》里，按出现的多少再请出 17 个：露 · 海 城 · 叶 · 凤 鹭 · 蜂 虾 · 虎 牛 猿 · 琴 书 笔 茶 笛 香（「虾」书里不常见，是为齐白石添的）。同时补了一批别名：石即岩，池、湖归水，李、梨归花，渔归舟，宫归楼，塞、关归城，鸥归鹭，鸾归凤，浪、潮、涛归海，瑟归琴，箫、管归笛，卷归书，墨、砚归笔，炉归香——这些字在题句里都会点亮，对仗也多了许多。
- 「旗 车 神 人 马」是戏里的人物与车马仪仗，**只在「人间词话」的卷中出现**——首页的字钮不列，拼音、手写也不认。现在首页可写 82 个字，全库 87 个。
- **对仗**：程序读出书里所有「甲对乙」，逐字配对。写下一个字，它的对家会在字钮里亮起；两者同在画中，题一句「云对雨」并奏一声。
- **题句**：每落一字，从全书里挑一句含它、且最贴合眼前画面的句子，竖排题在右侧。
- 别名也算数：书里的「鸿」就是雁，「蛩」就是虫，「釭」就是灯，「玉兔」「金乌」是月和日。

## 两种不靠输入法的写法

### 手写判定

打开「手写」，在纸上写一个字，停笔不到一秒，程序判断它是首页 82 个能活的字里的哪一个：

- 有把握：直接判定，手迹的墨点游成楷书，再化形。
- 像但不确定：列出几个候选，几秒后取第一名，也可以自己点。
- 拿不准：只列候选，等你点；不点就化成墨。
- 完全不像：手迹化成一团真的墨。

判法不依赖任何外部数据：把手迹归一到 64×64，取 256 维的「方向线素特征」，与用本机几种字体（黑、楷、仿宋、手写体）画出的模板比余弦相似度，再按笔画数略作修正。代码在 `js/hand.js`。

阈值是拿规整的合成笔画和乱涂标定的（15 个字各 6 种抖动，90/90 判对），**没有用真人手迹测过**，潦草的字可能要多点一下候选。

### 内置拼音

打开「拼音」，字母进一条贴着笔尖的小笺：`sh` 列出「山 水」，`shan` 整拼唯一就直接落字；`yu` 有「雨 鱼」，按空格取第一个、按数字选。退格删字母，Esc 取消。只认首页那 82 个字。

## 画法：水墨

万物都按水墨来画，不勾死线、不平涂：

- 形体是一层层半透明的淡墨和软边墨团叠出来的晕染，浓淡自己过渡；
- 轮廓只在要紧处提几笔由粗到细的墨线；
- 颜色只点一点淡朱、赭、花青。

**几种笔法**（`js/fauna.js` 里的 `MS.ink`），人物、马和新添的物象都靠它们：

| 笔法 | 是什么 | 用在哪 |
| --- | --- | --- |
| 湿笔 | 一笔蘸墨，起处浓、去处淡，边上积一圈水痕 | 虾身、衣带、袖 |
| 飞白 | 枯笔扫过，一丝一丝，中间露着纸，越到梢上越枯 | 马鬃马尾、虎纹、须发 |
| 钉头鼠尾 | 起笔一顿，随即收细，拖出长尾 | 衣背一笔、马的脊线与小腿、牛角 |
| 兰叶描 | 一笔之中提按两三次，粗细相间 | 衣纹、裙摆 |
| 没骨 | 不勾轮廓，一块墨就是一块体积，要紧处再积浓 | 马身、牛身、虎身 |

- **马**是大写意（徐悲鸿画马的路子）：一大笔淡墨写出躯干，墨在臀与肩上积成两团浓的，脊背留一线亮；鬃尾浓墨枯笔，迎风往后甩；腿是几根劲线，蹄子焦墨一点。
- **虾**学齐白石：头胸一笔淡墨，当中压一点浓墨是虾脑；腹五节，一节一笔，透着纸；须六根，长而劲；偶尔一弹，倒退着窜出去。
- **牛**学李可染：浓墨一团是牛，背上坐着吹笛的牧童。
- **人物**兼工带写：面与手留白，只提几根匀细的铁线，点一点胭脂；士人的袍是泼墨（淡墨铺底、背侧压浓、襟前留亮），仕女的衣是留白加兰叶描的衣纹；发、冠、须用浓墨，梢上飞白。

**龙**照传统龙纹的「九似」来画：角似鹿，头似驼（隆额、长吻、如意鼻），项似蛇，腹似蜃，鳞似鱼，爪似鹰；另有鬣、须、髯、腮刺，背鳍如焰，肘毛如火，尾散如扇，身作波浪游走，旁有如意云头，追一颗火珠。掉头时翻一个身，背总朝天。

## 四时：草木山水跟着季节换形

写「春」「夏」「秋」「冬」，世界不是换一层滤镜，而是画里已有的东西各自变过去——不是一刀切，是三四秒里慢慢长、慢慢落：

| | 春 | 夏 | 秋 | 冬 |
| --- | --- | --- | --- | --- |
| 山 | 新绿，山脚点桃花 | 浓绿，脊上苔点 | 赭黄，点丹枫 | 顶上积雪，留白 |
| 水 | 漂着落花 | 浮萍 | 落叶 | 浮冰，流得慢了 |
| 柳 | 才出嫩芽，柳絮飞 | 长足了，浓 | 黄而稀 | 落尽，只剩丝 |
| 花 | 满树的花 | 花谢，叶长足，结果 | 叶红了，一片片落 | 只剩枝，积雪，梢上小苞 |
| 梅 | 花将尽，新叶 | 叶绿，结青梅 | 叶黄 | 凌寒独开，枝上有雪 |
| 荷 | 小荷才露尖尖角 | 叶圆花开 | 莲蓬，叶黄 | 残荷，茎折叶垂 |
| 菊 | 一丛新苗 | 含苞 | 盛开 | 枯了头，带霜 |
| 竹 | 新笋 | 墨叶正浓 | 黄了几片 | 叶上、节上积雪 |
| 松 | 抽出新绿的松烛 | 苍翠 | 如常 | 每丛针上顶一团雪 |
| 草 | 短而嫩，间有野花 | 长而密 | 黄了，梢上结穗 | 枯短，根上盖雪 |

林、枫、叶、兰、露、茶也各有变化；蝶与蜂冬天不见，燕子秋去春来，虫声到冬天歇了。

做法：`World` 里有一组分量 `w.sea`（春夏秋冬各占几分），换季时此消彼长；各样东西画的时候用 `w.by(春, 夏, 秋, 冬, 平日)` 调和一个数（叶长、花开几分、雪厚），用 `w.hue(...)` 调和一种颜色，所以过渡是连续的。山的四时颜色是另画的四层，与墨山同形，按分量叠上去。

## 人间词话：把一篇古文演成一幅手卷

点右上的「词话」，选一卷，卷轴向两边滚开，铺满画面。手卷从右往左看；整卷只有一个镜头沿着它走，从头到尾不切换。

**卷一 ·《洛神赋》**（魏 · 曹植，全文八十五句）分十段：卷首 → 归途 → 洛川 → 惊鸿 → 仪容 → 嬉游 → 众灵 → 云车 → 诀别 → 怅归。
仿顾恺之《洛神赋图》的办法，同一个人在卷中一再出现，一段一个情节。

**卷二 ·《琵琶行》**（唐 · 白居易，序八句、诗四十四联）分九段：卷首 → 江头 → 闻声 → 初弹 → 曲终 → 京城 → 飘零 → 天涯 → 青衫。
整卷是一条江、一个夜晚；只有「京城」一段是她口中的往事，过一重云雾天亮成白昼，再过一重云雾回到江上。

**画是你写出来的。** 原文里有些字空着（卷一 47 处，卷二 42 处）。镜头走到那里就停下，等你把字补上；补对了，这个字在画里活过来，画才往下走。补字有三种办法：

| 办法 | 怎么做 |
| --- | --- |
| **写** | 直接在画上写这个字，停笔后判定（只在给出的四个候选里认） |
| **选** | 点画面下方四个候选字里的一个 |
| **描** | 画里有这个字淡淡的古字形，拿笔描过半，它顺着历史长成今天的字（古 → 楷） |

写错、选错只提示一声，不往下走。

| 其他操作 | 效果 |
| --- | --- |
| 滚轮 / `←` `→` / 点卷下的段名 | 在已经写出来的那一截里来回看（触屏：拖动画面） |
| 「自在」或空格 | 字自己补上，从头走到尾 |
| 点画中人 | 衣带飘举 |
| 「收卷」或 `Esc` | 卷起来，回到原来的纸上 |

第一次开卷，画铺开后会蒙一层提示，讲怎么拉动画卷、怎么补字；一动就收，之后不再出现。

**空哪个字，看原文的意思。** 每一处空的字，化出来的东西就是赋文那一句说的东西：
「日既西倾，＿殆马烦」补「车」，车才出现；「睹一丽＿，于岩之畔」补「人」，洛神才立在水边；
「翩若惊＿，婉若游＿。荣曜秋＿，华茂春＿。髣髴兮若轻＿之蔽＿，飘飖兮若流＿之回＿」——鸿、龙、菊、松、云、月、风、雪，这些比喻要你一个个写出来；
「六＿俨其齐首」补「龙」，六条龙来驾云车；「沾繁＿而至＿」补「霜」「曙」，天才亮。

**琵琶声是听的，诗里拿看得见的东西去比它——卷二就把这些比喻一样样演出来，并且各配一段合成的琵琶：**

| 诗句 | 补的字 | 画里 | 声里 |
| --- | --- | --- | --- |
| 转轴拨＿三两声 | 弦 | 她开始拨弦，声纹一圈圈荡开 | 疏疏三声 |
| 大弦嘈嘈如急＿ | 雨 | 真下一阵急雨 | 低弦轮指 |
| 大＿小珠落玉盘 | 珠 | 大珠小珠落在玉盘上弹跳 | 一串颗粒，珠子每弹一下应一声 |
| 间关＿语＿底滑 | 莺、花 | 黄莺绕着花枝 | 带倚音的碎句 |
| 幽咽＿流冰下难，＿泉冷涩弦凝绝 | 泉、冰 | 石隙流泉，江面结冰、裂纹 | 越来越疏的滑音，然后无声 |
| 银＿乍破水浆迸 | 瓶 | 一只银瓶颤一颤，炸开 | 四弦齐扫 |
| 铁＿突出＿枪鸣 | 骑、刀 | 五骑伏鞍挺枪冲过江面，刀光一闪 | 连扫，蹄声如鼓 |
| 四弦一声如裂＿ | 帛 | 一幅白帛从一头撕到另一头 | 一声裂响 |
| 唯见江心秋＿白 | 月 | 月出，江心一柱碎光 | 两声泛音 |

别处也照原文来：「枫叶荻＿秋瑟瑟」补「花」，岸边的荻抽出白穗；「移＿相近邀相见」补「船」，她的船荡过来；「犹抱琵琶半遮＿」补「面」，她才出来；
「夜深忽＿少年事」补「梦」，船上浮起一团少年时的门楼灯火；「江州司马青＿湿」补「衫」，司马的袍子慢慢洇成青色。

换景不靠切镜头，靠镜头自己的动作：

- **平移视差**：远山、近岸、水面各走各的快慢；
- **推近拉远**：从岸上远望，推到洛神身前，再拉开看众灵与云车；
- **升降**：云车一段镜头抬向云里；
- **云雾过场**：近处的云雾走得比画快，掠过去就换了一景；
- **昼夜流转**：卷一「轻云蔽月」入夜，「太阳升朝霞」天明，卷尾「沾繁霜而至曙」；卷二「夜送客」入夜，忆京城时回到白昼。

做法：整卷画在一条高 1000 单位的长平面上；每一段有自己的一小方天地（一个 `World`），所以字库里会活的字能直接落进去；
人物、车马、云车、鲸鲵是 `js/scroll.js` 里按水墨画法写的；一卷自己的东西（卷二的客船、琵琶女、京城门楼，以及落珠、银瓶、铁骑、裂帛这些转瞬即逝的灵）写在那一卷自己的文件里。
要加一卷，照 `js/luoshen.js` 或 `js/pipa.js` 写一份段落表即可。

## 计划：世界风格切换

现在只有一种风格——**水墨晕染**。之后打算加：

- **沙画**：墨变成沙，流体改成堆积与滑落
- **像素**：降分辨率、限色板、抖动
- **皮影**：镂空的剪影、关节、幕后的灯

代码已为此留了口子：万物的颜色都经 `world.col()` 取，流体的最终成像只在 `fluid.js` 的 `display` 着色器里——换风格主要是换这两处。

## 已知的局限

- 需要 WebGL（半浮点纹理）。没有的话字和灵还在，墨不流动。
- 输入法候选框的位置由浏览器决定，个别浏览器不会贴着笔尖。
- 古文字只收了有可靠公有领域字形的字；打一个不在库里的字，只会演示楷、隶两体。
- 乐器是合成的，神似而已，不是采样。
- 手写判定只认字库里的字，阈值没有用真人手迹校过。
- 手卷里的人物是程序画的写意小像，只求神似；《洛神赋》里的问答与心理描写（如「余情悦其淑美兮」一段）只有赋文，没有单独成画。
