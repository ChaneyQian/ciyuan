# 词源

**字溯其源 · 声律成境** —— 在宣纸上写一个字，看它从楷书一路退回甲骨文，再活成它所画的那件东西。

写「山」，三座并立的峰先在字里显形，然后真的隆起成山；写「月」，半轮甲骨月散作一团墨，月亮从墨里浮出来；
写「龙」，它会跟着你的笔尖游。写下「云」之后，字钮里的「雨」会亮起——因为《声律启蒙》开篇就是「云对雨」。

纯静态网页：一个 `index.html` 加几份脚本，没有构建步骤，没有依赖。

## 运行

```bash
python -m http.server 4180
```

然后打开 <http://localhost:4180>。直接双击 `index.html` 也能用。

要发布成网站：把仓库推到 GitHub，在 Settings → Pages 里选 `main` 分支根目录即可。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 键盘直接打字（中文输入法） | 字落在笔尖（鼠标所在处），溯源、化形 |

| **留影** | 存一张 PNG，带印章与题句 |

## 三件事

### 一、字形溯源

每个字先以今天的楷书落纸，然后倒着走完它的历史：

**楷书 → 隶书 → 小篆 → 金文 → 甲骨文 → 化形**

越往回越像画，走到最古的象形时题一句字源（「象群峰并立之形」），墨散开，字变成实物。

- 甲骨文、金文、小篆是真实的历史字形，轮廓数据在 `js/glyph-data.js`（125 个字、291 个字形）。能活的 44 个字里有 36 个带古文字，其中 23 个能一直退到甲骨文。
- 楷书、隶书用系统字体（Windows 的楷体 / 隶书，macOS 的 Kaiti SC / Libian SC）。机器上没有隶书就跳过这一体，不拿别的字体冒充。
- 某一体没有可靠字形的字只演示有的那几体。「雷 松 莺 鹤 蝶 楼 灯 昼」这 8 个字在来源里没有古文字字形，目前只有楷、隶两体。
- 渐变的做法：每一体画到离屏画布，在墨迹里撒 1500 个点，相邻两体的点就近配对，墨点在两组位置间游走。

### 二、中式乐器

全部用 WebAudio 现场合成，不带任何音频文件。

| 乐器 | 做法 | 谁在用 |
| --- | --- | --- |
| 古琴 | Karplus–Strong 拨弦，暗而长，带吟猱与走手音；另有泛音 | 山、松、菊、月；底乐 |
| 古筝 | 明亮的拨弦，刮奏 | 水、虹、柳、荷、舟 |
| 琵琶 | 短促颗粒，轮指、扫弦 | 雨、花、草、剑 |
| 笛 / 箫 | 正弦泛音 + 气声 + 倚音 + 颤音 | 竹、梅、莺 / 云、烟、霞、风、雁、夜 |
| 编钟 / 磬 | 非谐泛音叠加 | 钟、楼、日 / 雪、星、灯 |
| 鼓 / 木鱼 | 降调正弦 + 噪声 | 鼓、雷、龙 / 溯源时每退一体一声 |

- 音高只用五声音阶（宫商角徵羽）。写「春夏秋冬」会换调：春-角、夏-徵、秋-商、冬-羽。
- **平仄入乐**：每个字落纸时古琴应一声——平声字是平直的长音，仄声字是带滑音的折音。
- 凑成一副对仗时，上下句各一声，再合为五度。

### 三、词库：《声律启蒙》

`js/shenglv-data.js` 是清人车万育《声律启蒙》全文（上下卷三十韵，九十阕）。词库的一切都从这份文本里算出来：

- **能活的字**共 44 个，都是书里反复出现的物象：日月星云雨雪风雷虹霞烟 · 山水 · 竹松柳梅花荷菊草 · 鸟燕雁莺鹤 · 蝶虫鱼龙 · 舟楼钟鼓剑火灯 · 春夏秋冬夜昼空。
- **对仗**：程序读出书里所有「甲对乙」，逐字配对。写下一个字，它的对家会在字钮里亮起；两者同在画中，题一句「云对雨」并奏一声。
- **题句**：每落一字，从全书里挑一句含它、且最贴合眼前画面的句子，竖排题在右侧。
- 别名也算数：书里的「鸿」就是雁，「蛩」就是虫，「釭」就是灯，「玉兔」「金乌」是月和日。

## 结构

```
index.html
css/style.css
js/
  fluid.js         水墨流体（WebGL）。染料三通道 = 墨 / 朱 / 青 的浓度
  world.js         世界容器、调色、天象与山水（日月星云雨雪风雷虹霞烟 山水）
  flora.js         草木（竹松柳梅花荷菊草）
  fauna.js         禽鸟虫鱼（鸟燕雁莺鹤 蝶虫鱼龙）
  things.js        器物（舟楼钟鼓剑火灯）
  lexicon.js       能活的字、平仄、字源；从《声律启蒙》算对仗与题句
  glyph.js         字形溯源的渐变
  audio.js         乐器合成
  main.js          输入、界面、主循环
  shenglv-data.js  《声律启蒙》全文（生成）
  glyph-data.js    古文字轮廓（生成）
tools/             生成上面两份数据的脚本
```

加一个新字：在 `lexicon.js` 的表里添一行，在 `MS.Kinds` 里写它的 `create / update / draw`，在 `audio.js` 的 `BLOOM` 里给它一句乐声。

## 计划：世界风格切换

现在只有一种风格——**水墨晕染**。之后打算加：

- **沙画**：墨变成沙，流体改成堆积与滑落
- **像素**：降分辨率、限色板、抖动
- **皮影**：镂空的剪影、关节、幕后的灯

代码已为此留了口子：万物的颜色都经 `world.col()` 取，流体的最终成像只在 `fluid.js` 的 `display` 着色器里——换风格主要是换这两处。

## 已知的局限

- 需要 WebGL（半浮点纹理）。没有的话字和灵还在，墨不流动。
- 输入法候选框的位置由浏览器决定，个别浏览器不会贴着笔尖。
- 古文字只收了有可靠公有领域字形的字；打一个不在库里的字，只会演示楷、隶两体。
- 乐器是合成的，神似而已，不是采样。
